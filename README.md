# Malvin C Vpn

A WhatsApp multi‑device bot built with **Baileys** and **Node.js**, powered by **Handsome Tech in Zimbabwe**.  
Malvin C Vpn provides a simple **pairing site** where you enter your WhatsApp number (with country code, e.g. `263************`) to generate a pairing code and link your WhatsApp account.  

The bot comes with **126 commands**, including fun, utility, economy, game, and download features like `.play` and `.video`.

---

## ✨ Features
- Multi‑device WhatsApp bot using Baileys
- Dark, green‑themed pairing site with code‑style font
- 126 built‑in commands:
  - 🎮 Game commands: `.roll`, `.flip`, `.quiz`, `.play`
  - 💰 Economy commands: `.balance`, `.work`, `.gamble`, `.shop`
  - 📥 Download commands: `.video`, `.music`, `.download`
  - 🛠 Utility commands: `.ping`, `.uptime`, `.status`, `.weather`
  - 🎉 Fun commands: `.joke`, `.fact`, `.quote`
